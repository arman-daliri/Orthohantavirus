===================================================================================
THE MAFFT SPLIT -- a deliberate, recorded platform-version divergence
===================================================================================
MAFFT 7.525 has NO Windows build. The official Windows page offers 7.222, 7.304,
7.312, 7.313, 7.427, 7.450, 7.490 and 7.526 -- 7.525 is not among them. The two
release tracks genuinely diverge: the source page carries 7.525 but not 7.526, and
the Windows page carries 7.526 but not 7.525.

  Windows (this machine) : MAFFT 7.526   <- cannot be 7.525; no such build exists
  Linux / conda (Omarchy): MAFFT 7.525   <- environment.yml pin, obtainable there

7.525 and 7.526 are a maintenance release pair. MAFFT's own version string dates the
7.526 build 2024/Apr/26 and the 7.525 source tarball was posted 2024/Mar/19 (server
Last-Modified). NO ALGORITHMIC CHANGE BETWEEN THEM IS DOCUMENTED -- but that is an
absence of evidence, not evidence of absence, and this project does not run on
undocumented equivalence. The reproducibility fixture ASSERTS alignment-content
agreement across the two rather than assuming it. See the D6 note in the design doc.
